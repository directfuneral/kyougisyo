# 遺産分割協議書 / 協議証明書 自動作成ツール

行政書士業務向けに設計した、遺産分割協議書・遺産分割協議証明書のブラウザ完結型作成ツールです。

## 特徴

- **リアルタイムプレビュー** — 入力内容がA4文書イメージに即時反映されます
- **2書式対応** — 遺産分割協議書 / 遺産分割協議証明書をワンクリックで切替
- **財産種別ごとの入力フォーム** — 預貯金・不動産・自動車・有価証券に最適化
- **定型条項の自動挿入** — 後日発見遺産条項・死後事務費用条項をチェックで制御
- **Word (.docx) 出力** — 明朝体形式のWordファイルをワンクリックでダウンロード
- **印刷 / PDF出力** — ブラウザの印刷機能でそのままPDF保存可能
- **法定相続情報PDF読込** — PDFからテキスト抽出（ベータ機能）
- **ダーク / ライトモード対応**
- **サーバー不要** — 静的HTMLファイル1枚で完結。インターネット接続があれば動作します

## 使い方

### ローカルで開く

```
index.html をブラウザで直接開くだけで使えます。
```

### GitHub Pages で公開する場合

このリポジトリを GitHub Pages にデプロイすると、URLでアクセスできます（下記の手順参照）。

## ファイル構成

```
isan-tool/
├── index.html   # ツール本体（単一ファイル完結）
└── README.md    # このファイル
```

## 外部ライブラリ（CDN読込）

| ライブラリ | 用途 |
|---|---|
| [Tailwind CSS](https://tailwindcss.com/) | レイアウトユーティリティ |
| [docx.js](https://docx.js.org/) | Word(.docx)ファイル生成 |
| [FileSaver.js](https://github.com/eligrey/FileSaver.js/) | ファイルダウンロード |
| [PDF.js](https://mozilla.github.io/pdf.js/) | PDFテキスト抽出 |
| [Google Fonts](https://fonts.google.com/) | Noto Sans JP / Noto Serif JP |

すべてCDNから読み込むため、インターネット接続が必要です。

## 注意事項

- 本ツールが出力する書式はあくまで参考書式です。実務での使用にあたっては、各案件の内容に応じて必ず専門家が確認・修正を行ってください。
- 入力データはブラウザ上のみで処理され、外部サーバーには送信されません。

## ライセンス

本ツールは事務所内部利用・改変を自由に行えます。再配布・商用利用の条件は運用者の判断に委ねます。
